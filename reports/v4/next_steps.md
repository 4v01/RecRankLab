# 下一轮优化方案：按验证证据分层推进

当前结果不是模型能力上限：每个新基础模型只搜索两条参数配置，工业系统的多模态、社交与曝光标签也不在MovieLens中。下列方案是下一轮待验证假设，不能写成本轮已经获得的提升。

1. **先修正排序目标匹配，再扩大网络。** 对HistoryTower做匹配预算的LogQ修正对照。用户均衡、用户内均匀采样正例时，物品边际采样概率应按训练用户正例数估计，不能直接套用全局评分频率。校正与不校正两组使用相同架构、温度网格、早期检查频率和数据；候选、预算及失败规则先冻结。参考[采样偏差校正双塔](https://research.google/pubs/sampling-bias-corrected-neural-modeling-for-large-corpus-item-recommendations/)。本轮没有实现或验证其增益。
2. **检验近期兴趣和数据时间错配。** 当前双塔只保留最近50个正例作为上下文，却从全部训练正例采样目标；下一轮对照严格历史前缀目标与现方案。所有输入、负例屏蔽与采样概率都只来自当前拟合分区，不能用验证/测试未来正例做黑名单。时间特征需来自可用历史或明确可用的查询时刻，不能悄悄加入事后才知道的信息。
3. **针对低活跃用户和长尾补内容特征。** 使用官方电影类型/年份建立MF＋内容或DCN对照，特征词表与统计只在训练数据确定。分组边界沿用训练支持度，报告所有分组及总样本权重，不能删除困难用户来降低总体RMSE。超过半年的历史间隔误差较高只是关联证据，时间偏置是否有收益仍需匹配对照。
4. **容错作为独立目标检验。** 以训练/验证上下文缺失构造预先冻结的增强策略，测试前确定选择规则，同时报告完整上下文与缺失场景的权衡。本轮压力测试保持参数不变，只模拟推理输入缺失，不等于训练数据损坏或新用户冷启动。不能根据已知测试压力结果调好参数后再声称独立确认。
5. **用同一数据集做样本量对照。** ML-1M与ML-10M的人群、目录、时期和量表不同。要检验“更多训练样本是否提高精度/稳定性”，另立固定目标集与候选目录的训练抽稀协议，并重跑全部比较方法。该受控消融另表呈现，不替换当前主协议，不通过缩小候选目录或丢弃冷目标提升指标。
6. **计算预算先于模型扩张。** 优先保留验证融合与稀疏/因子方法；EASE正则网格应考虑用户规模的变化，并披露额外搜索预算。获得合适GPU并完成设备适配后才补齐原定ML-10M AutoRec及融合的六条缺失记录。不得以一轮计时、缩小样本或更短训练冒充原完整计划。

下一轮统一门槛：先冻结候选、损失、信息边界和资源上限；只按验证指标选型；每个最终逻辑配置测试一次；保存全部失败、负面结果和额外预算。当前benchmark已经反复使用，确认性结论应留给预先冻结的新留出集或外部数据。
